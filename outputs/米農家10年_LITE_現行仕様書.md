# 米農家10年 LITE 現行仕様書

## 1. ゲーム概要

タイトル: 米農家10年 LITE

岡山で3町の田んぼを引き継いだ若手農家が、5年間の米農家経営を体験するブラウザゲーム。  
プレイヤーは季節ごとに行動を選び、能力、資金、信用、農機コンディション、経営面積を変化させながら、収穫と決算を繰り返す。

リアルな農業シミュレーターよりも、以下の体験を優先する。

- 行動する
- 能力が上がる
- ときどきイベントが起こる
- 収穫結果を見る
- お金や面積が増える
- 拡大しすぎると管理が難しくなる
- 最後に称号が出る

## 2. プレイ期間

- 期間: 5年間
- 1年: 8ターン
- 総ターン数: 40ターン
- 1プレイ目安: 7〜10分

## 3. 初期状態

- 経営面積: 3町
- 資金: 300万円
- 借金: 0万円
- 栽培力: 30
- 経営力: 30
- 体力: 70
- 信用: 30
- 農機コンディション: 70

## 4. 年間ターン構成

1. 1〜2月: 今年の経営計画
2. 3〜4月: 田んぼの準備
3. 5月: 田植え
4. 6月: 水と雑草
5. 7月: 夏の管理
6. 8月: 病害虫との戦い
7. 9〜10月: 収穫
8. 11〜12月: 販売と決算

7ターン目終了時に収穫結果を表示する。  
8ターン目終了時に年間決算を表示する。

## 5. 基本能力

栽培力: 収量、天候被害、病害虫対応に影響する。  
経営力: 経費、農地拡大、補助金、大面積管理に影響する。  
体力: 行動で減少する。低いと収量低下や不利なイベントにつながる。  
信用: 農地相談、農機借用、販路、良いイベントに影響する。

## 6. 経営データ

- 資金
- 借金
- 経営面積
- 農機コンディション
- 今年の天候
- 今年の米価
- 今年の収量補正
- 今年の販売価格補正

## 7. 行動

季節ごとに選べる行動が変わる。  
さらに、毎年の状況によって一部の時期に臨時行動が左端へ追加されることがある。これにより、通常4択の時期がたまに5択になる。

主な行動:

- 水管理
- 水管理準備
- 勉強
- 営業
- 機械整備
- 休養
- 除草対策
- 防除
- 栽培研究
- 丁寧に田植え
- スピード重視
- 丁寧に収穫
- スピード収穫
- 応援を頼む
- JA中心で販売
- 高値販売

11〜12月は、JA中心で販売と高値販売の2択だけにする。臨時行動は追加しない。  
高値販売の行動タイルには体力-10を表示し、内部処理でも体力を減らす。  
JA中心で販売の行動タイルには、安定販売、信用+1、価格+1%を表示する。

臨時行動の例:

- 早朝見回り
- 土づくり
- 地域の手伝い
- 資材チェック
- 取引先訪問

行動ボタンには、原則としてマイナス面を表示しない。  
例: 体力消費、資金減少、農機消耗などは行動選択前には見せず、ターン後の結果画面で表示する。
ただし、高値販売の体力-10はプレイヤー判断に必要なコストとして表示する。

## 8. 1ターンの流れ

1. 現在の年、月、天候、米価、田んぼ状態を見る
2. 行動を1つ選ぶ
3. 短いドット演出が再生される
4. 必要ならランダムイベントが発生する
5. イベント選択肢を選ぶ
6. 1ターンの結果を表示する
7. 「次の時期へ」で次ターンへ進む

1ターンの結果には以下を表示する。

- 年月
- 選んだ行動
- 発生イベント
- 結果メッセージ
- 栽培力、経営力、体力、信用、資金、借金、面積、農機、収量補正、販売補正の増減

## 9. 農地拡大イベント

毎年、以下の時期に農地拡大系イベントが必ず発生する。

- 1〜2月
- 3〜4月
- 11〜12月

発生回数は毎年1〜2回。  
最低1回は1〜2月または3〜4月に発生する。2回目がある場合は11〜12月に発生する。

1〜3年目の農地提案面積は、固定の0.8町ではなく、0.6〜1.2町の範囲でランダムに提示する。  
4年目以降は、信用やイベント内容に応じて小規模・大規模の提案が出る。

対象イベント:

- 近所の農家が引退
- まとまった農地相談
- 地主から相談

通常ランダムイベントより優先して発生する。

## 10. ランダムイベント

イベントは `events.js` にオブジェクト形式で管理する。  
将来AIイベント生成に差し替えやすいよう、ゲーム本体とイベントデータを分離する。

イベント例:

- 近所の農家が引退
- まとまった農地相談
- 地主から相談
- 補助金採択
- 中古農機の話
- トラクター故障
- 畦が崩れる
- 良い資材情報
- 田植機故障
- 苗不足
- 田植え日和
- 雑草大量発生
- 用水トラブル
- 生育絶好調
- 猛暑
- 台風接近
- カメムシ発生
- 病気が出る
- 飲食店から直接取引
- 地域で評判になる
- コンバイン故障

## 11. 天候

毎年ランダムで天候を決定する。

- 好天
- 平年並み
- 猛暑傾向
- 長雨傾向
- 台風多め

天候は収量に影響する。  
水管理や特殊能力によって、猛暑などの被害を軽減できる。

## 12. 米価

毎年ランダムで米価を決定する。

- 安値予想: 13,000円 / 60kg
- 平年並み: 15,500円 / 60kg
- 高値予想: 19,000円 / 60kg
- 超高値: 25,000円 / 60kg、発生率5%

営業、高値販売、直接取引、ブランド米などで販売価格補正が入る。

## 13. 収量計算

基準収量: 450kg / 10a

簡易式:

```text
収量 =
450
+ 天候補正
+ 栽培力補正
+ 行動補正
+ イベント補正
- 面積過多ペナルティ
- 体力不足ペナルティ
- 農機不調ペナルティ
- 雑草・病害虫ペナルティ
```

収量は 280〜600kg / 10a に制限する。

農機コンディションと体力が両方低い場合、プラス補正だけに効率倍率をかける。

- 農機コンディション50以下かつ体力50以下: プラス補正 x0.8
- 農機コンディション30以下かつ体力30以下: プラス補正 x0.65

基準収量やマイナス補正そのものには倍率をかけない。

各ターンの行動選択によるプラス効果は120%にする。  
各ターンの行動選択によるマイナス効果は85%に軽減する。  
イベント、天候、決算などの結果は別扱いとし、行動選択そのものの手触りを少し簡単にする。

水管理、雑草対策、防除対策などの年内プラス項目も120%補正の対象にする。

## 14. 売上・経費・借金

1町 = 100a として計算する。

売上:

```text
俵数 = 収量 / 60 * 面積 * 10
売上 = 俵数 * 米価
```

表示は万円単位。

年間経費:

```text
面積 * 50万円 + 固定費30万円
```

特殊能力「数字に強い」がある場合、年間経費を10%軽減する。

資金がマイナスになった場合は100万円単位で自動借入する。  
年末に資金に余裕があれば自動返済する。

## 15. 面積過多ペナルティ

管理可能面積は、栽培力、経営力、体力から計算する。  
現在面積が管理可能面積を超えると、収量にペナルティが入る。

農地を増やせば必ず有利になるのではなく、能力や体力とのバランスを取る必要がある。

面積が増えるほど、各ターン行動時の体力消耗と農機消耗が少し増える。  
具体的な割合はプレイヤーに見せず、右側には「面積が広がるほど消耗が重くなる」と説明する。

## 16. 農機コンディション

農機は個別管理せず、0〜100の農機コンディションで管理する。

- 高い: 故障しにくい
- 低い: 故障イベントや収量ペナルティが起こりやすい

機械整備で回復する。  
田植え、収穫、通常作業で少しずつ消耗する。

## 17. 特殊能力

条件を満たすと自動取得する。

画面左側に「取得数 / 全特殊能力数」を表示する。  
未取得の特殊能力には、大まかな取得ヒントを表示する。
特殊能力を取得した瞬間は、ドット演出エリア上に「特殊能力開花」の通知を表示する。

- 水見の勘: 水管理3回以上。猛暑・水不足ダメージ軽減
- 顔が広い: 信用60以上。農地イベントが出やすい
- 整備上手: 機械整備3回以上。農機故障率DOWN
- 数字に強い: 経営力60以上。年間経費-10%
- 鉄人: 高体力を維持。体力消費DOWN
- ブランド米: 栽培力70以上かつ信用70以上。販売価格+10%

## 18. ドット演出

中央エリアに常設のドット演出エリアを設ける。  
自由移動型RPGではなく、行動選択後に短く再生される演出として扱う。

実装方式:

- HTML / CSS / JavaScript
- 画像素材なし
- CSSのピクセル表現とアニメーションで描画

演出対象:

- 田植え
- 水管理
- 収穫
- 耕す・水準備
- 防除
- 除草
- 機械整備
- 営業
- 勉強
- 休養

演出中は行動ボタンを無効化する。  
演出エリアをクリックするとスキップできる。

- 経営ルール: 経営力・栽培力・体力で管理可能面積が決まり、経営面積がそれを超えると収量と利益が落ちる

- ゲームログ
- 前回のログ: もう一度プレイ時に、前回プレイの結果概要と直近ログを表示する

スマホ表示では、ルールメモを折りたたみ式にする。  
スマホ縦画面は情報量が足りないため、横画面で進めるゲームとして扱う。縦画面では横向きプレイを促す案内を表示する。  
スマホ横画面では、左のステータス欄と右の経営データ欄を隠し、中央のプレイ画面上部に簡易HUDを表示する。

スマホ横画面HUD:

- 経営力
- 体力
- 信用
- 資金
- 借金
- 経営面積
- 農機コンディション

これにより、スマホ横画面では「ステータス確認」と「ターン進行」を同じ画面内で行える。

## 22. 最終結果

5年目の決算後に最終結果を表示する。

最終結果では「あなたの農家人生」カードを大きく表示する。

カード表示例:

```text
あなたの農家人生
5年目終了
経営面積: 8.4町
平均収量: 503kg/10a
純資産: 2,830万円
借金: 700万円

称号
「岡山のやり手農家」
```

「結果をシェア」ボタンを表示する。対応環境では共有、非対応環境では結果テキストをコピーする。

称号ごとに、最終カード内の農家ドットアニメーションを変える。  
エンディングの称号には、少し笑える一言を表示する。

表示項目:

- 純資産
- 現金
- 借金
- 経営面積
- 5年間平均収量
- 平均売上
- 平均経費
- 平均利益
- 最大収量
- 5年間総売上
- 能力
- 特殊能力
- あなたの5年間
